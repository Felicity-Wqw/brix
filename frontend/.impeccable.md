# Impeccable 设计上下文 — 物归校园

## Target audience
在校大学生（买家 + 卖家双身份），PC 端使用；答辩场景下还有课程评委观看。

## Use cases
浏览/搜索校园闲置 → 详情 → 面交/邮寄下单 → 晒出闲置回血；AI 估价与文案辅助发布。

## Brand personality / tone
- **温暖纸感的校园市集**：像校园里周末的跳蚤集市海报——纸张质感、墨绿油墨色、橙红价签，而不是 SaaS 后台模板。
- 关键词：可靠（面交优先）、亲切（同学之间）、利落（交易效率）。
- 唯一强调色 = 橙红价签色（价格），主色墨绿只做品牌与操作，不滥用。

## Design tokens（唯一权威来源：src/styles/index.css）
- 底色暖纸 `#f6f4ee`，卡片暖白 `#fffdf9`
- 主色墨绿 `#0e7a50`（hover 压深不提亮），浅绿衬底 `#e7f3ec`
- 文字墨绿黑 `#1c2a24`，禁用纯黑纯白
- 价格橙红 `#ff4d2e`，数字 tabular-nums
- 圆角 8 / 大件 14；阴影两层柔和，不用发光

## Constraints
- Vue3 + Element Plus（通过 CSS 变量深度定制，不脱离组件库）
- 仅 PC 1280px+，无移动端
- 登录/注册页（auth-page）有独立的毛玻璃视觉体系，不套用全局 token
